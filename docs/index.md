## Quickstart - create a repo using this template

```
uvx copier copy gh:pik-ecs/ecs-repo-template --trust my-new-project
```

Projects come with an optional, one-command [protected `main` branch](choices/branch-protection.md)
for when they're on GitHub.

## Background what is this?

This is a living template for repositories in the ECS group.

It encodes recommendations for ways to organise python projects, including the use of tools to manage dependencies, track and share data, and ensure code quality (among other tasks).

These recommendations, and the choices behind them, are documented (or soon to be documented) in the choices section of these docs.

The intention of this template is to provide a central location for "how we do things" in the group. This shouldn't be a straightjacket, but rather help us keep up to date with modern standards that help us work together, and save us rewriting boilerplate setup code.
