# .gitignore

[**gitignore.io**](https://www.toptal.com/developers/gitignore/) is a useful tool for generating a `.gitignore` file based on the languages, operating systems, IDEs, and tools you use.

Example: If you're building a Python project on macOS using VS Code:

1. Enter **Python**, **macOS**, and **Visual Studio Code** into gitignore.io.
2. It generates a `.gitignore` containing rules for files and folders commonly created by that combination of tools.
3. Copy the generated contents into your project's `.gitignore` file.

This saves you from having to know or remember all the tool-specific files that shouldn't be committed to Git.
